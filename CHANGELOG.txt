Version 3.0.16 - 2026-10-28
----------------------------
Comparison
- Previous release: 3.0.15, commit 2c7953d3.
- Latest available tag: 3.0.14. The newer 3.0.15 release commit is used as the release baseline to avoid repeating the changes already documented below.
- Compared 2c7953d3 with HEAD 7ed72aad and included the local 3.0.16 release metadata and documentation updates.

Added
- Added wtTrackRegistration after successful WooCommerce customer creation via My account and classic or Blocks checkout, using value 0, the WooCommerce shop currency, and status completed.
- Added an account-owned pending registration event that survives login redirects and is consumed on the first logged-in page. If automatic login is disabled, delivery waits until the first login.
- Added PHP regression coverage for the successful-creation hook, exact registration payload, shop currency, account isolation, one-time consumption, AJAX registration, and admin/cron/sessionless exclusions.
- Added browser regression coverage for registration dispatch, delayed tracker readiness, analytics consent, duplicate event IDs, and consent revocation.

Changed
- Allowed wtTrackRegistration through the existing browser event queue, retaining consent and tracker-initialization requirements.
- Extended WooCommerce documentation with registration timing, privacy, cache exclusions, manual checks, and delivery limitations.
- Updated README highlights and release notes; synchronized README.txt, style.css, and MADEIT_VERSION at 3.0.16.
- Included StyleCI formatting of PHP regression fixtures, tracking payload arrays, block helpers, icon registration, feedback, and eight generated asset metadata files. Asset dependencies and version hashes are unchanged; no block rebuild or dependency update is included.

Fixed
- No additional functional bugfixes beyond the new registration event lifecycle.

Removed
- No features, files, or dependencies were removed. No files were renamed.

Limitations
- Registrations require a WooCommerce storefront session. Admin and cron account creation are excluded.
- Registration payloads contain no account details and are dispatched only with WebsiteTool analytics consent.
- Once a pending event is emitted into a page, the server does not offer it again if consent remains absent or the browser closes; WebsiteTool delivery is not acknowledged.
- Actual WebsiteTool reception still requires a manual check on the registered domain.

----------------------------
Added

- Updated Container style-picker wrapping and empty-container editor sizing; refreshed affected Gutenberg build assets and metadata.
- Updated form submit-button width styling, editor honeypot visibility, and frontend block styling.

- Added a dedicated Video Lightbox npm workspace and lockfile with @wordpress/scripts ^26.0.0 and swiper ^11.2.7; no existing dependency manifest was changed.

Fixed
- Limited updater source-directory renaming to the updater's own theme, rejected invalid/error sources, and avoided renaming an already-correct directory.
- Added legacy separator attribute parsing and deprecated-save migration, and corrected separator alignment/style serialization.

Removed
- Disabled automatic loading of the custom image extension in functions.php; the extension files remain in the repository.
